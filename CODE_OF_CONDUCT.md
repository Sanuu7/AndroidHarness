# Code of Conduct

AndroidHarness is mainly built by one person, and contributors are welcome.
These rules apply to issues, pull requests, discussions, reviews, and anywhere
else you speak for the project.

## Be decent

- Talk about the code, not the person. Explain what breaks and what you would do
  instead.
- Assume good faith. A strange-looking change is often a misunderstanding or a
  different phone.
- Say what you actually tested. Don't say it works if you only built it.
- Remove tokens, private file paths, account names, and personal data from logs
  and screenshots before posting them.
- Be patient about replies, fixes, and features. Contributions are welcome, but
  there is no promised schedule.
- Don't present unverified AI output as fact, and don't submit generated code you
  can't explain.

## Not okay

- Harassing, threatening, or stalking someone, including following them from
  thread to thread.
- Insults, slurs, sexual comments, or jokes about someone's identity.
- Sharing someone's private information without their permission.
- Spamming, deliberately derailing threads, impersonating someone, or organizing
  review bombing.
- Asking for or using help from this project to attack someone else's device,
  account, or service.

## Reporting a problem

Security problems go to [SECURITY.md](SECURITY.md). Everything here is about
behavior.

Report a behavior problem privately if you can:

- Use GitHub's **Report abuse** link on the comment or account if it breaks
  GitHub's rules.
- Otherwise open an issue that only asks for a private contact, with no details
  in the public issue. You will get a private way to reply:
  https://github.com/Sanuu7/AndroidHarness/issues/new

Say what happened, where, and include links or screenshots if you have them. Only
the maintainer reads reports, and they are handled privately. Reporting in good
faith will never count against you, and retaliating against someone who reports
is a violation.

## Enforcement

What happens depends on the case. It can be a private note, a warning, editing or
removing a comment, locking a thread, or blocking someone from the repository.
Threats or sharing private information may lead straight to a block. Reports made
in bad faith count as a violation; honest mistakes don't.
